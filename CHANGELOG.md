# 2.4.0

Added:

1. Skyrim VR support, including VR controller bindings and prompts attached to objects in the world. Requires ImGui VR Helper, installed separately.
2. A scrollable List layout with one activation button for the selected prompt. Scroll with the mouse wheel or D-pad Up/Down.
3. In-game editing of the default theme and loaded themes, including special-effect settings and colors.
4. Text backgrounds with adjustable color, padding, and rounded corners.
5. Customizable progress circles and List scroll indicators.
6. A fading activation pop effect, with an option to animate only the icon.
7. Multiple special effects on the same theme.

Fixed:

1. A crash that could occur when quitting after using a prompt.
2. Remaining prompts fading in again when another prompt is dismissed or removed.

Improved:

1. Theme settings are grouped in one menu section, with more spacing and clearer help text.
